# Alcove

Journal numérique des lieux qui ont une âme. Maquette du site (projet "Hôtels avec une âme"), bilingue FR/EN, pilote Cappadoce.

- **Maquette en ligne (privée) :** https://claude.ai/artifact/DnAjchfG2J5EQP1EaC7qzf
- **Concept :** journal éditorial de luxe, pas un site de réservation. L'arche (l'alcôve) est la signature visuelle, avec des ouvertures et fermetures de panneaux.

## Fichiers

| Fichier | Rôle |
|---|---|
| `V3.dc.html` | Version premium en cours, **FR/EN**. Rideau d'entrée, arche du hero qui s'ouvre au défilement, deux portes qui ouvrent un dossier par maison, menu plein écran, index éditorial. |
| `Main.dc.html` | V2 conservée (3 langues EN/FR/RU). |
| `plates/`, `cappadoce/` | Illustrations de remplacement et scripts qui les génèrent (plus utilisées). |

Les fichiers `.dc.html` sont au format Design du canvas Claude. Les images pointent vers les assets du canvas (`/_blob/...`) : ils ne s'ouvrent pas tels quels dans un navigateur. Les photos ne sont pas dans ce dépôt.

## Avant toute mise en ligne

1. Confirmer les droits des photos (actuellement provisoires).
2. Faire relire les faits par les hôtels (Sacred House, Gamirasu Cave Hotel).
3. Réserver le domaine (`alcovejournal.com` recommandé).
